EduReach SL Project
EduReach SL is a learning support system designed to help students in Sierra Leone access educational materials.
EADME – EduReach SL
Project Overview
EduReach SL is a proposed educational support system designed to make learning easier and more accessible for students in Sierra Leone, especially those in communities with limited internet access.

The system will help learners access educational materials, study different subjects, take practice quizzes, check their scores and receive feedback to improve their understanding.
Main Features
- Lesson Search: Allows learners to search for lessons using subjects and topics.
- Offline Learning: Provides access to lessons stored locally without requiring constant internet access.
- Practice Quizzes: Allows students to answer questions and test their knowledge.
- Score Calculation: Automatically calculates quiz scores and displays results.
- Learning Feedback: Provides recommendations based on students' performance.
- Content Management: Allows authorized administrators to add and update learning materials.
Flowgorithm Features Used
The project uses important programming concepts that can be represented in Flowgorithm, including:
- Input and Output: To collect users' choices and display information.
- If/Else Statements: To make decisions based on user input.
- Loops: To repeat menus and quiz questions.
- Variables: To store scores, answers and user choices.
- Functions: To separate the system into smaller tasks.
- Calculations: To calculate quiz percentages and results.
Project Objectives
The main objective is to support quality education by providing learners with simple and accessible learning resources. The project also supports Sustainable Development Goal 4 (SDG 4 – Quality Education).
Technologies and Tools
- Flowgorithm
- Pseudocode
- Flowcharts
- GitHub for version control and project storage.
Conclusion
EduReach SL aims to make education more accessible, encourage independent learning and help students improve their academic performance, even in areas with limited internet connectivity.
